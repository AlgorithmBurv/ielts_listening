Gemini API Error 429 (RESOURCE_EXHAUSTED)

Batas penggunaan API Key Anda saat ini telah habis atau telah melebihi batas batas panggilan per menit (RPM/RPD).

Solusi Langkah Cepat:

  • Tunggu 30 - 60 detik (Rate Limit RPM reset otomatis).
  • Gunakan API Key Gemini baru / cadangan lain.
  • Audio yang berhasil ter-generate tetap tersimpan di Cache.
